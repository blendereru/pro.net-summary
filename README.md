## About
Chapter-by-chapter reading and writing my own summary of the [Pro.Net Memory Management, 2nd edition](https://link.springer.com/chapter/10.1007/979-8-8688-0453-3_1#DOI)
book.
## Motivation
I have already read this book before, but found myself forgetting about memory concepts over time. This is because not putting enough effort on practical implications of the book.
Various tools and examples were covered, and not trying them on your own results in bad comprehension of basic concepts.
## How is repository organized ?
If the use-case is covered in the book, I will cover it on my own and put my results as a project under the specific chapter. Each chapter's `README` will contain
information I found useful and unique, as well as comparing with the relevancy of the current `.NET` runtime(as the latest edition of the book is of year 2024, and thus
concepts may not be relevant anymore).
